Este decorador permite que la clase esté disponible para ser proporcionada e inyectada como dependencia. Además brinda configuraciones para limitar el alcance del servicio.

Opciones:
- provideIn -> limita el alcancé del servicio a una parte específica de la aplicación. Recibe el valor predeterminado _root_. Este hace que el servicio este disponible para toda la aplicación.

Nota: aplicar ejemplo en caso se limite el uso del servicio.
